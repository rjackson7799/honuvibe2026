## 4. Decisions for Ryan (each with a recommendation)

**D1 — Hero rotator and "Trending now" data source.**
Recommend: **`getPublicCatalog()`** (B2: cached anon, explicit columns, partner items excluded), not `getVaultTrending`.
- `getVaultTrending` uses the cookie client, which would make Home dynamic again. It also does `select('*')`, pulling the premium `url` / `embed_url` (see memory `premium-vault-url-leak`), and its view-count order is meaningless at 0 views.
- Rotator: up to 5 items, `is_featured` first, then newest (that's the catalog's order within track; re-sort in the page by `is_featured desc, publish_date desc`).
- Trending chips: the 4 newest by `publish_date` not already in the rotator.
- Titles use `title_jp` on `/ja` (all present), falling back to `title_en`.
- Empty catalog (query error) → hide the eyebrow row and the chip row. Never show placeholder titles.
